# Enable Cut/Paste in Terminal

The terminal attempted to access the clipboard but it was denied. Open Royal , Enable clipboard access in "Preferences - Connection Types - Terminal - Plugin Settings - Applications in terminal may access clipboard".

RoyalTSX main menu | Settings | Terminal | Control/Right+Click pastes clipboard

# Apple Right Click is control - https://support.apple.com/en-au/guide/mac-help/mh35853/mac
# Prefix is control + b


- https://herdr.dev/docs/configuration/#keybindings

# Rename Workspace

Command + Click the spaces and rename.

or type
herdr workspace rename 1 Workspace1
